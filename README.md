# Agent Tools Runner

**Use any chat LLM as a coding agent. No API key, no IDE plugin.**

`atr` is a human-in-the-loop agent harness written in Go. It lets a chat LLM inspect and edit your local project through structured JSON requests, with every operation visible to you and confined to your workspace.

## Install

Download the latest binary from [Releases](https://github.com/KraiwitC/agent-tools-runner/releases), rename it to `atr` (`atr.exe` on Windows), place it on your `PATH`, and run ATR from your project directory.

```sh
atr
atr --auto
```

Type `/help` inside ATR for all commands.

## Quick Start

1. Run `atr --auto` in your project directory.
2. Paste the copied bootstrap prompt into your chat LLM.
3. Ask: "Add configuration validation. Investigate first and propose a plan before editing."
4. Review and approve the plan, then copy each ATR request from the chat. Auto mode detects and executes the copied request, then copies the JSON response for you to paste back into the chat.

Run `atr` without `--auto` to paste each JSON request manually.

## Safety Model

> [!IMPORTANT]
> ATR executes requests generated by an LLM. Review modification plans carefully and keep the Bash allowlist limited to commands you trust.

- Filesystem operations stay inside the selected workspace, and symbolic links are rejected.
- Edits require the current SHA-256 and exact, unique targets; create, copy, and move never overwrite.
- Files are limited to 10 MiB; `.agents` and `.git` are read-only to protocol operations; delete removes only hash-matched files or empty directories.
- Bash runs only allowlisted commands with a capped timeout and rejects shell control characters plus `--output` and `--no-index`.

## Operations

- **Inspect:** `tree`, `search`, `ranked_search`, `read`, `read_range`, and `inspect`
- **Modify:** `edit`, `create`, `copy`, `move`, `mkdir`, and `delete`
- **Bash:** Runs explicitly allowlisted commands through the host shell.

Read operations return bounded structured results, with SHA-256 hashes where applicable. Modifying operations use exact paths, hash checks, and no-overwrite behavior.

## Workspace Configuration

Run `/init` to create the `.agents` folder without overwriting existing files:

```text
.agents/
  atr.json          # default bash allowlist: git status, git diff, git log, git show
  skills/
    <skill-name>/
      SKILL.md      # listed in the prompt using its frontmatter description
```

`atr.json` controls the Bash allowlist.

ATR includes `AGENTS.md`, `PLAN.md`, and available skill descriptions in the generated bootstrap prompt. After changing project instructions, plans, skills, or the allowlist, run `/prompt` and start a new conversation.

## Development

```sh
go run ./cmd/atr
go fmt ./...
go test ./...
go vet ./...
go build -o dist/atr ./cmd/atr
```

Cross-compile with `GOOS` and `GOARCH`, for example `GOOS=windows GOARCH=amd64 go build -o dist/atr.exe ./cmd/atr`.
